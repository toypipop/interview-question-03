คู่มือใช้งาน GreenBook

รายการเริ่มที่ รออนุมัติ → พิจารณาเป็น อนุมัติแล้ว หรือ ไม่อนุมัติ

  1. สร้าง กด + สร้างรายการ พิมพ์ชื่อ แล้วบันทึก
  2. แก้ไข / ลบ ปุ่มในแถว — ได้เฉพาะรายการที่ยังรออนุมัติ
  3. พิจารณา ติ๊กรายการ (เลือกหลายอันได้) → “อนุมัติ” หรือ “ไม่อนุมัติ” → ใส่หมายเหตุ → ยืนยัน
  4. ย้อนกลับ ปุ่ม “ยกเลิก” ในสองแท็บผล ดึงกลับเป็นรออนุมัติ และล้างหมายเหตุ
  5. ข้อมูลตัวอย่าง ปุ่ม MockUp (ซ้ายสุดของแท็บรออนุมัติ) — ลบข้อมูลทั้งหมดทุกสถานะ แล้วสร้างชุดตัวอย่างใหม่ รออนุมัติ 10 · อนุมัติ 5 · ไม่อนุมัติ 5 · กู้คืนไม่ได้ ใช้สำหรับทดลองเท่านั้น

Esc หรือคลิกพื้นที่นอกกล่อง = ปิด · เปิดซ้ำที่ปุ่ม “คู่มือใช้งาน”
